# Learning in Public

Structured notes and notebooks I write to learn — and to explain — the foundations of data science
and computational biology. Each folder below links to its own repository.

| Repository | Description |
|---|---|
| [**ML_Algorithms**](https://github.com/rcwang2024/ML_Algorithms) | Machine learning from foundations to cutting edge: classical ML, deep learning, transformers, GNNs and RL in Jupyter notebooks |
| [**Mathematics_for_ML**](https://github.com/rcwang2024/Mathematics_for_ML) | Mathematics for machine learning with code: linear algebra, probability, optimization, information theory and beyond |
| [**Bioinformatics_practice**](https://github.com/rcwang2024/Bioinformatics_practice) | Hands-on bioinformatics curriculum: genomics, transcriptomics and proteomics workflows and pipelines |
| [**Notes_on_Python**](https://github.com/rcwang2024/Notes_on_Python) | Python for data science, machine learning and computational biology: 20 Jupyter notebooks |
| [**Notes_on_R**](https://github.com/rcwang2024/Notes_on_R) | R for data scientists and computational biologists: 22 R Markdown modules from basics to Bioconductor |
| [**Notes_on_LinuxGit**](https://github.com/rcwang2024/Notes_on_LinuxGit) | Linux command line and Git for data scientists and computational biologists |
| [**Notes_on_AWS**](https://github.com/rcwang2024/Notes_on_AWS) | AWS notes for data science workflows: EC2, S3, IAM, Lambda and deployment |

## Clone everything

```bash
git clone --recurse-submodules https://github.com/rcwang2024/learning-in-public.git
```

To update the links to the latest commits: `git submodule update --remote && git commit -am "Update submodules"`.
